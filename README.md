# 3D LiDAR-Based Shelter Damage Inspection System

## Overview

This project presents an autonomous inspection system for rectangular shelters using a 3D LiDAR sensor in Gazebo. The system scans the shelter, detects structural damage, classifies damage into Face, Edge or Corner regions, estimates severity, and generates an inspection report.

## Features

- 3D LiDAR Scanning
- Shelter Inspection
- Point Cloud Generation
- Damage Detection
- Face/Edge/Corner Classification
- Severity Estimation
- Repair Cost Estimation
- Automatic Report Generation

## Technologies

- ROS2
- Gazebo
- Python
- OpenCV
- Open3D
- NumPy
- RViz2
